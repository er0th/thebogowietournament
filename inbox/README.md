# 📥 Inbox — tu wrzucasz pliki

Wejdź w ten folder na GitHubie → **Add file → Upload files** → przeciągnij pliki → **Commit changes**.
Potem napisz Claude'owi „ogarnij inbox”. Pliki zostaną przekonwertowane, podpięte i stąd usunięte.

## Nazwy plików (wtedy przypiszę je bez pytania)

| Nazwa | Co się stanie |
|---|---|
| `player-torrac.wav` | dźwięk profilu Torraca |
| `foto-hazeg.jpg` | zdjęcie profilowe Hazega |
| `class-druid.mp3`, `class-druid-2.mp3` | głos klasy (kolejny wariant) |
| `race-orc.mp3` | głos rasy |
| `combo-undead-paladin.mp3` | głos konkretnego combo |
| `final-cokolwiek.mp3` | dźwięk po wygraniu Bo7 |
| `meme-cokolwiek.png` | obrazek do memów — napisz, gdzie ma iść |

Dowolny format dźwięku (wav, ogg, mp3, m4a) i obrazka (jpg, png, webp). Inna nazwa też zadziała, wtedy po prostu dopytam.
